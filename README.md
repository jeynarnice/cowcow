## CowCow - ระบบจัดการฟาร์มน้ำนมวัว
โปรเจกต์ CowCow คือระบบจัดการฟาร์มน้ำนมวัว พัฒนาโดยใช้ PHP และ MySQL รองรับการจัดเก็บข้อมูลลูกค้า พนักงาน จำนวนน้ำนม ราคาขาย รวมถึงการสร้างบิลซื้อขายน้ำนมระหว่างลูกค้าและพนักงาน

## โครงสร้างระบบ
ระบบประกอบด้วย 4 ตารางหลักในฐานข้อมูล cowcow:

employee --> ข้อมูลพนักงาน เช่น ชื่อ อีเมล เบอร์โทร รหัสผ่าน 
customer --> ข้อมูลลูกค้า เช่น ประเภทลูกค้า ที่อยู่ เบอร์โทร 
cow --> ข้อมูลล็อตน้ำนม เช่น ปริมาณ คุณภาพ ราคาทั่วไป/สมาชิก 
bill --> ข้อมูลบิลการซื้อขายน้ำนม ระบุลูกค้า พนักงาน และล็อตที่ซื้อ

## เทคโนโลยีที่ใช้
- PHP 
- MySQL / MariaDB
- phpMyAdmin
- HTML

## การทำงาน
- ลงทะเบียนและเข้าสู่ระบบสำหรับพนักงาน
- เพิ่ม/แก้ไข/ลบข้อมูลลูกค้า พนักงาน น้ำนม และบิล
- มีการ join ข้อมูลกัน
